# Python 3 Migration

This package has been migrated from Python 2 to Python 3.8 to ensure compatibility with NSO 6.4 and higher.

## Changes Made

1. Updated exception handling to use the `as` keyword
2. Updated package metadata to specify Python 3 compatibility
3. Ensured all code is compliant with Python 3.8 standards

## Requirements

- Python 3.8 or higher
- NSO 6.4 or higher
